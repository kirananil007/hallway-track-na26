# Code of Conduct

This project follows the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Hallway Track is an unofficial community project and is not run by CNCF. To report a problem
with behavior in this repository (issues, pull requests, side-event listings), contact the
maintainer, [@kirananil007](https://github.com/kirananil007), through GitHub.

Side-event listings must also follow the event's own Code of Conduct. We'll remove listings
that don't.
